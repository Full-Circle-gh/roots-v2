The rule the grid follows: six columns. A block asks for one column per number it carries, and packs into the row. Three numbers take half the page, two take a third, one takes a sixth. Add a number to Delivery tomorrow and it widens on its own — nobody edits a layout.

The rule the hero follows: the lead number is always the money, and it is Inter at 44px — one step up from a section card, not a poster. It reads first because it stands alone above a hairline, not because it shouts. Beside it goes whichever list is asking loudest today; on a calm day that slot holds Recent orders instead.

The rule the line follows: the day line is the only thing on the page that moves. It draws itself in once when the page settles, and then the tip breathes — a slow pulse, the shop being alive. The dotted line is a typical Friday, so the "▲ 16%" above has a picture. No axes, no gridlines, no tooltips: the big number is the y-axis, and the hour marks are the x. If the user asked for reduced motion, it is simply a drawn line.

The rule that stops repeats: every fact has exactly one home. New customers is a Customers number, so the hero strip dropped it and now carries two cells. Today's revenue is the hero, so Money shows the week and the month instead. Refunds and Invoices each got their own narrow block, so the old all-clear list — which said the same three things in words — is gone.
