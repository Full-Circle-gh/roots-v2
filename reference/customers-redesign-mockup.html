  • “Active base” card. It always equals total minus blocked — a duplicate number. recommend
  • “Blocked 0” card. An empty state shouldn’t own a card. Blocked appears only when it exists (flip the toggle above). recommend
  • “Include blocked” checkbox. Replaced by the amber Blocked chip that only shows when the count is above zero. recommend
  • Red ▼43% delta. Fewer signups isn’t an alarm. It becomes the words “quieter than usual” in graphite. recommend

Changed

  • Tier and Last seen are now sort, not filter. Click the column header to sort by it; click again to flip direction. All columns work this way — try it in the table above. Same information, one control instead of two. recommend
  • Phone lives under the name. One column instead of two; em-dashes disappear.
  • Base tier goes quiet. Seed renders as a plain cream pill; only earned tiers (Sprout+) get the sage tint, so an upgraded customer stands out.
  • Last login → “Last seen”. Today 14:35 / Yesterday 23:24 / Jul 3 — no repeated dates.
  • Zeros dim. A page of ¥0.00 shouldn’t shout as loud as real balances.
  • New customer button is ink, not gold. Dusk stays reserved for automation; this page has none.
