What changed & why

Header

2 buttons instead of 6

Message and Edit profile are the everyday actions — they stay as calm bordered buttons. Sign out all devices and Block move into a More menu (drawn open here). Block sits last, in brick, behind a divider.

Dropped entirely: the View display-options popover and Reset to new user (test).

Gold "Message" button dropped — nothing here needs to shout.

Identity

Pill wall → eyebrow + facts

Eyebrow carries ID + joined date, same pattern as the order drawer. Only the tier stays as a pill (plus red Blocked when it applies). Joined / last login / sessions / app build move into the two facts cards. The openid shrinks to one truncated mono row with a copy button.

Numbers

3 tiles → 1 snapshot band

Orders · Points · Wallet as one cream strip, one figure each, one quiet sub-line. Zero values render grey ("never topped up"), not four rows of ¥0.00. Adjust becomes a small underlined text action.

The dropped rows (Refunded, Expired, Admin adjust…) aren't lost — they only appear in the sub-line when non-zero, and the full history stays in the folds below.

Chart

Shorter, with a summary

96px tall, quiet month labels, sage bars. The headline ("2 orders · ¥473.00 in 12 months") reads faster than the bars for sparse customers.

Folds

Ledgers get count hints

Each fold shows what's inside before you open it: counts, "none", or "no errors in 7 days" in sage. Recent orders moves to the top (most used); Diagnostics drops down and still auto-opens when there are errors.

Open question

Where should Block live?

Recommended: in the More menu (shown). Alternative: keep Block visible as a bordered brick button if staff use it often enough that two clicks is too slow.
