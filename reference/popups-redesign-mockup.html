What changed, and why

Removed: the three-sentence header paragraph (now one lede) · the per-card Edit button (the whole card opens the editor, like Orders rows) · the status pill crammed next to the name (one status word + the switch say it once) · in the editor: the Internal-name field (auto-filled from the title), the Enabled checkbox (the list switch owns it), and Dismissible as a top-level toggle (Advanced, default on).

Added: you can finally see each pop-up from the list — poster in A, thumbnail in B/C · grouping by what matters (Live first, then Scheduled, then Off) · countdown language ("ends in 23 days", "starts in 4 days") instead of bare dates · an empty state that starts the three real jobs — announce, coupon, closure — instead of a magnifying glass · "Run again" on ended pop-ups (duplicate with fresh dates) · C only: "Today on your store", which pop-up actually fires on each page, with a quiet amber note when two overlap.

Colour discipline: Dusk appears once — the New pop-up CTA (the screen's one primary, same as Orders' New order). Sage means live, amber means scheduled, graphite means off. Brick exists only on Delete inside the editor. Nothing on this page is decorated.

Same data, same API: every option reads the exact fields the current page saves (name, pages, trigger, frequency, window, content, CTA). This is a re-layout, not a schema change — the rebuild swaps markup and CSS, and savePopup() keeps its payload.
