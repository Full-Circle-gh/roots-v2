Option notes

  • A · head row — a 44px icon button beside the language control. Follows the existing head-row pattern (icon-only, min 44px touch target). Available even with an empty basket and on the settle screen if wanted later. Recommended: it never competes with the money controls.
  • B · rail foot — a labelled button beside Hold / Discount. Most discoverable, but the foot row gets crowded and it is only visible on the till view.
  • C · under total — a quiet text link. Zero layout weight, but easy to miss in a rush.
  • Centered modal vs right-side sheet: the sheet slides over the order rail (matches the hold/discount pickers' feel) and keeps the basket visible; the modal is the classic popup you asked for and reads as a separate tool.
  • “Copy result” is optional — the till has no text field to paste into during a sale, so it can be dropped in the real build.
  • Real implementation: strings go through cuT(en,cn), the 计算器 pair must be declared in docs/tacet-delivery-vocabulary.md, popup is a plain hidden-toggled div inside .till (no new dependencies), keys ≥ 52px on the tablet.
