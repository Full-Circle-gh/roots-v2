The first paint

Right now the admin shows an empty page while the shell loads. Four ways to fill it, all built from the mark you already have: the waveform settling into a straight line, with the Dusk dot at its end. Dusk stays what it always means — the system is doing something.

A · Settle

Recommended

The waveform draws itself and comes to rest. The dot lands last and breathes until the app is ready. The brand story, told in 1.5 seconds.

B · Quiet dot

The finished mark, held still. Only the dot breathes. Nothing draws, nothing travels — the most silent option, and the cheapest to paint.

C · Pulse

The mark is already at rest. A Dusk pulse runs the settled line and is absorbed by the dot, over and over. Loops honestly — a slow load never looks frozen.

D · The line only

Drop the waveform. A hairline grows from the centre, the wordmark rises through it, the dot arrives. Reads as calm — but it throws away the mark that makes the brand.

How it would work

  • The splash lives inline in retail-admin.html — its own markup and its own style block, above the stylesheet link. It has to paint before any CSS or JS file downloads, otherwise it can't cover the gap it exists to cover.
  • For the same reason it cannot wait for Fraunces. The wordmark falls back to Georgia until the webfont lands. Option A hides this well: the word fades in at 900ms, by which time the font is usually there.
  • The shell removes it once the rail and dashboard are painted: add a class to fade it out over 260ms, then drop the node. If the shell throws, the splash must still leave — a hard 8-second timeout, so a broken boot never looks like a hung one.
  • It reads the saved theme from localStorage before painting, so a dark-mode user never gets a white flash.
  • A is my pick. B is silent but tells the user nothing is happening. C loops forever, which is the safest thing for a slow connection, but the pulse is busier than the brand wants. D is beautiful and throws away the waveform. A tells the brand story once, then falls back to a breathing dot — which is C's honesty without C's noise.
