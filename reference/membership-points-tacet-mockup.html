What went away: the 8-column tier spreadsheet (on a phone the perks boxes render one character per line), the exposed Key column (the key derives from the English name and shows read-only in the editor), and the three paragraphs of intro copy — every control now gets one short line, and only where it earns its place.

What's new: a plain-¥ outcome line so the operator can sanity-check the math at a glance; member counts on each tier (context for choosing thresholds); amber hints inline while you type instead of toast errors at save time; and in Option B, the shopper's own Membership card pinned beside the form.

The Dusk budget: zero. Nothing on this page is automation, so nothing on it may be purple. Sage marks members present and tiers reached; amber flags the one setting worth a second look; the only dark buttons are ink.

Field parity: both options carry every stored field — earn pair, earn basis, point value (redeem rate), expiry months, points-cover-shipping, and per-tier key / names EN+CN / threshold / multiplier / perks EN+CN. Two save buttons remain two saves, matching the two config blobs behind them.
