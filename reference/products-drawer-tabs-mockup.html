Drawer tabs — four options 560px · Stock 30 · a designed page
Today
The strip breaks four type rules at once, and they compound into something that reads as small print rather than as the drawer's main navigation.
Basics…
Faults
  • Tabs are 13px — the caption size, used for the drawer's primary navigation
  • "DESIGNED" is uppercase, banned outright (§1.6)
  • That mark is 10px and the count 11px; nothing may go under 13px (§1.3)
  • Both are weight 600; only 400 and 500 exist
  • Dusk means "the system did this" and the page already spends its one Dusk on Add product (§1.8)
A · Same pattern, properly sized — recommended
15px, real breathing room between tabs, taller hit area. Nothing structural changes — this is the strip it was always meant to be, at the size the type scale actually allows. "Designed" becomes a quiet fact in the neutral palette, because it describes the product, not an automation.
Basics…
Trade
  • Reads as navigation, not small print
  • Every rule satisfied, nothing invented
  • Same shape as the page's own sub-view strip
  • Tabs sit left, so the right of the strip is empty
B · Equal columns
Each tab takes a quarter of the width and centres its label. Fills the strip edge to edge and gives the largest possible target for each one.
Basics…
Trade
  • Biggest targets, no wasted strip
  • Underline length reads as a real segment
  • "Page Designed" is far wider than "Basics", so equal columns make the gaps uneven
  • Breaks from how the page's sub-view strip sits
C · Segmented pill
A cream track with the active tab as a raised pill — the shape the editor used before the drawer rebuild, and the one the sales-range chips still use. Unmistakable about which pane is open.
Basics…
Trade
  • Strongest signal of the open pane
  • Familiar from the range chips
  • §1.7 reserves the pill for filters; underline is the pattern for switching what you are looking at
  • Little room left for the count and the Designed mark
D · Bigger, with the icons back
Option A plus the pane icons, which were dropped when the drawer was 480px and there was no room. At 560px they fit, and they give each tab a fixed anchor the eye can return to.
Basics…
Trade
  • Most substantial strip of the four
  • Icons are fixed landmarks, useful on a strip you hit constantly
  • No room left for the Designed mark beside Page
  • Four icons is decoration if the four words already read clearly
Fixed in all four
Designed is sentence case, 13px, weight 400, in the neutral palette. It was uppercase 10px weight 600 in Dusk — the uppercase ban, two breaks of the type scale, and a second Dusk element on a page whose one Dusk is already spent on Add product. Same for the 30, which was 11px weight 600.
