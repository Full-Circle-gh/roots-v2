What changed & why

Picture 1 · empty boxes

6 boxes → 2 cards + 1 strip

Customer, Payment, Fulfilled by and Ship by were each one short line in a full box — lots of empty rectangle. They collapse into one facts list (label → value rows).

Ship to stays a real card (multi-line address + edit). Receipt drops to a slim strip instead of a whole box.

Picture 2 · shipment icons

Icons removed

The ✈ / 🚚 glyphs are dropped — the card is a shipment, so the word carries it. Label shortens to Air / 空运 and Land / 陆运. “Not shipped” reads as a quiet dot.

Header · actions

Own row, calm

Eyebrow on top, big order no + status, then actions on their own row below (like the live drawer) — no cramped button top-right. Forward action = calm bordered; Refund = ghost. The one emphasised (ink) action is each parcel’s Mark dispatched, where the packer acts.

Item rows

Weight dropped

Meta line is now just SKU · qty · unit cost (e.g. 4-450 · ×1 · @ ¥71.00). The size was redundant — the SKU already pins the variant.

Printing · rethink

Just a print button

The receipt row is now a single Print receipt button — no “printed on…” status, no JD-waybill text.

The shipping label (JD waybill · 面单) and the auto-print toggle moved out: the label prints from the waybill in the tracking card, auto-print lives in Settings · Printing.

Languages

Never glued

Chrome, store name and item names all swap with the EN / 中文 switch — you only ever see one language, matching the brand rule and the live drawer.

System

Tacet palette

Ink = the single strong action · Cream = quiet fills · Amber = attention · Sage = done · Brick = danger only.
