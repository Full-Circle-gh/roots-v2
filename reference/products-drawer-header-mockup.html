What it proves
  • Tags wrap to a second line rather than pushing Expand off the edge
  • Three tags is the realistic ceiling — §1.10a caps a stack at three
  • Save status changes colour and word together, so "Saving…" is never mistaken for saved
  • If a product ever needs a fourth tag, the fourth belongs in the pane, not the header
Fixed in all four, regardless of which wins
Sales is sentence case at 13px, weight 400. Live it is "SALES" — uppercase, 10px, weight 600, which breaks the uppercase ban (§1.6) and the type scale (§1.3, no size under 13px, no weight over 500) in one label. Every .pd-sec-h and .pd-card-h in the editor has the same problem, so it is one rule to fix, not one label.
