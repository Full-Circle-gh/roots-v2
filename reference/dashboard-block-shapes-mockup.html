Mockup Dashboard block shapes — three ways to stop every section being the same rectangle.

The blocks should not all be the same shape

Right now Orders, Customers, Inventory and Delivery each get one full-width card with room for three numbers. Inventory and Delivery only have two, so the card is padded out. And a section with nothing waiting takes exactly as much of the page as the one that needs you. Below: three shapes, same tokens, same words.

Option A

Bento by weight

The page is a six-column grid. A block takes as many columns as it has things to say. Three numbers fill the width; two numbers take half, and two halves share a row. Nothing is stretched, nothing is padded.

The rule the code follows: a block asks for one column per number it carries, plus one for its attention line, and the grid packs them. Add a fourth number to Delivery tomorrow and it grows to full width on its own — nobody edits a layout.

Option B

Hero and tiles

One number is the reason you opened this page: what the shop took today. It leads, at a size you can read across the room. Everything else is a tile, and a tile only grows when it has a list to show you.

Option C

Quiet sections shrink

Recommended

A section that needs nothing from you is one calm line, with its numbers still on it. A section that is asking for something opens into a card. The page re-shapes itself through the day, and the only thing that grows is the thing you have to do.
