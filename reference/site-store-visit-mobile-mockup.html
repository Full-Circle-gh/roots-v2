Store visit block — mobile

The live card stacks map, title, address band, primary button, and three map links in one white shell. On a phone the address lines are colliding (your screenshot). These are layout options on the same content: Roots · Yuexiu, English address, Get directions, Apple / Google / Amap.

What is going wrong today — mountStoreVisit in public/site.html moves the address into .sb-st-visit-addr with margin: 0 -22px, but the visit card body on mobile never gets the inner padding the desktop side has (padding: 36px 40px). The Bear title, oat address band, and any Chinese address line compete in the same vertical slice. Fix can be CSS-only; these mockups show how much to restructure.
