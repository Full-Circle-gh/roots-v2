What changes either way

Eight things are wrong with the page as it ships today, independent of which layout wins. The first one is a live bug, not a style note — it is visible in the screenshot.

A missing space glues seven labels Live bug

The runtime splitter considers a text node only when it contains space, middot, space. Seven labels on this page write the middot with no space in front of it — 弹窗小标题(中文)· Popup eyebrow — Chinese — because the Chinese half ends in a bracket. The node is never considered a pair, never split, and both languages render at once in both language settings. The English-first labels beside them are spaced correctly and do split, which is exactly what the screenshot shows: one label style showing one language, the next showing two. They are also written Chinese-first, which would fail the second gate even with the space restored — so the fix is both: a real · and English on the left.

§1.11 · retail-admin.html:10344, 10352, 10360, 10368, 10387, 10395, 10403. Grepped file-wide: two more of the same shape sit in the cutoff card just above (10244, 10274), and nowhere else in the product — every other unspaced middot is a separator inside an already-translated cuT(), which is correct.

Every label on the page is uppercase

label.stacked is text-transform: uppercase; font-weight: 600, and the card titles use .fc-sec at mono 700 caps. Two rules broken at once: uppercase is banned outright, and Inter above 500 reads as shouting. The replacement is 13px Inter 500, sentence case, Graphite.

§1.6 · retail-admin.css:5471, 1051 — 95 uppercase rules remain in the file; this page's rebuild removes its own.

There is no master switch card

The on/off control is the first of eight fields in a wrapped flex row, indistinguishable from the interval box beside it. A Console leads with the master switch in its own card and states the consequence in words. Nothing dims when it is off, either — the twenty fields below stay fully lit and fully editable while the feature does nothing.

A4 · master switch first, own card; master off → groups at 55%, never hidden.

Twenty fields, one wrapped row, no descriptions

Every field is a label stacked on a control inside one .row with flex-wrap, so the layout is decided by the window width rather than by meaning. A Console row is a label and a one-line description on the left with a single control on the right. That one change is most of the redesign.

A4 · one control per row.

The lede under the title is a purpose line

"For products flagged 'Made fresh in batches'…" would read identically tomorrow, which is the test. Either it becomes a real status line, or the title stands alone. Both options here take the title alone: the master switch card already reports the state, so a status line would only duplicate it.

§1.7 · purpose lines were cut 2026-07-17 and stay cut.

Two Dusk save buttons on a page that should have none

Both saves are btn btn-primary. Dusk means one thing — Tacet did this for you — and configuration is the merchant acting. A Console has no Dusk CTA at all; its saves are secondary, pinned to the group they save.

The Dusk rule, §1.8, A4.

Blank means off, and only a code comment says so

"Ready from the kitchen" left empty is the off switch and the default — it changes whether a sold-out fresh item is offered for today or for the next batch day. On screen it is a bare — placeholder. The rule belongs in the row's description, where the merchant is.

Recorded at retail-admin.html:10327 (§74) and nowhere the merchant can see.

Two cards and two saves for one subject

"Reschedule cutoff" is a second card holding a single hour, about the same products as the card above it. It folds into the rhythm as one more row. The cards that remain need stable ids — the command palette jumps to individual setting cards, and there is no convention yet.

A4 · every group needs a stable id. Decide the convention before eight Consoles exist.

Open, and not decided here

The Chinese for any new or restructured label is not in these frames — mockups render one language, so nothing has been composed yet. Whichever option is picked, its strings land in docs/tacet-delivery-vocabulary.md in the same commit as the code, marked composed, with the live candidates that were rejected.
